# PPT 生成与素材使用合并说明

这份说明把原本的 `PPT 生成` 流程和新加入的 `素材区` 合并到一起，方便你直接按一套流程完成 PPT 制作。

## 这个页面现在有两种输入

1. **主题输入**
   - 直接输入一个演示主题
   - 例如：`企业 RAG 方案分享`
2. **素材输入**
   - 在素材区里粘贴文本、链接，或者上传文件
   - 这些素材会跟当前会话绑定，参与后续生成

你可以只用主题，也可以只用素材，更推荐两者一起用。

## 先理解两种 PPT 模式

### 1. 常规类 PPT

适合：

- 产品介绍
- 项目汇报
- 方案说明
- 课程讲解

流程大致是：

1. 输入主题
2. 系统做主题分类和网页检索
3. 生成结构化大纲
4. 选版式
5. 生成元素级 schema
6. 套用轻量设计
7. 导出 PPTX

### 2. 研究类 PPT

适合：

- 基于论文研究结果做汇报
- 从研究会话直接生成讲稿和 PPT

流程大致是：

1. 先在 `论文研究` 里完成研究
2. 在研究结果里点 `基于本研究生成 PPT`
3. 系统读取研究报告 `final_report.md`
4. 再结合素材区里的内容生成 PPT

## 素材区怎么用

素材区默认是折叠的，不会挡住聊天内容。  
你可以展开它，然后按下面两种方式喂素材：

- **粘贴文本**
  - 适合提纲、摘要、关键结论、参考链接
- **上传文件**
  - 适合 `pdf`、`docx`、`pptx`、图片等文件

### 推荐输入方式

如果你只是想让 PPT 更像你自己的内容，建议这样放：

- 主题：告诉系统这次 PPT 的主方向
- 文本：放你已经整理好的要点
- 文件：放参考文档、示意图、已有 PPT

系统会把这些内容统一保存到当前会话的素材包里。

## 素材会在哪些阶段被使用

素材不是只保存起来，而是会参与生成流程：

- `outline`
  - 帮助生成更贴近你内容的大纲
- `layout`
  - 帮助决定哪些页面更适合双栏、图文、总结页
- `schema`
  - 把素材拆成标题、要点、引用、图片、图注等元素
- `manuscript`
  - 把素材写进讲稿或附录
- `quality`
  - 用来检查是否有多余调试文本、过长句子、页数不一致
- `regenerate`
  - 基于已保存工件重新导出，不必重新跑一遍整个流程

## 一条最常见的使用路径

### 场景 A：你只有一个主题

1. 进入 `PPT 生成`
2. 直接输入主题
3. 发送
4. 等系统生成
5. 下载 PPTX

### 场景 B：你有自己的材料

1. 进入 `PPT 生成`
2. 展开 `素材`
3. 粘贴文本或上传文件
4. 回到主题输入框
5. 输入主题并发送
6. 系统会结合素材一起生成

### 场景 C：你先做了研究，再做 PPT

1. 先进入 `论文研究`
2. 得到研究报告
3. 回到 `PPT 生成`
4. 展开 `素材`，补充你自己的文件或文字
5. 点 `基于本研究生成 PPT`
6. 系统会读取研究报告并结合素材生成

## 生成后你还能做什么

生成结果里通常会有这些操作：

- `文件下载`
  - `PPTX`
  - `plan`
  - `manuscript`
  - `quality_report`
- `质量检查`
  - 查看当前 PPT 的检查结果
- `重新生成`
  - 用已保存工件重新导出 PPT

## 素材区为什么默认折叠

因为它更像“辅助工作区”，不是主对话区。  
默认折叠以后：

- 不会挡住对话
- 页面更清爽
- 需要时再展开即可

## 最小示例

你可以直接这样做：

1. 在素材区粘贴：

```text
1. 背景
2. 问题
3. 方案
4. 实施
5. 总结
```

2. 再上传一份参考文档或示意图
3. 在 `PPT 生成` 输入：

```text
企业知识库建设方案
```

4. 发送

系统会优先围绕你给的主题和素材来编排内容。

## 你可以把这条线理解成什么

简单说，现在的 PPT 流程已经是：

**主题 + 素材 + 研究报告 -> 结构化大纲 -> 版式选择 -> 元素 schema -> 轻量设计 -> 导出 PPTX**

这也是后续继续优化的基础。

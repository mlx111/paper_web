# PPT 素材使用指南

这份说明讲的是：如何在 `PPT 生成` 页面里，把你自己的素材喂给系统，并让这些素材参与后续的 PPT 规划、讲稿和导出。

## 你可以放什么素材

现在素材区支持两种入口：

- 粘贴内容
  - 适合粘贴要点、摘要、段落、参考链接
- 上传文件
  - 适合上传 `pdf`、`docx`、`pptx`、图片等文件

系统会把这些输入统一保存到当前会话对应的素材包里，后续生成 PPT 时自动读取。

## 推荐的使用顺序

### 1. 先切到 `PPT 生成`

在左侧模块里进入 `PPT 生成`。

### 2. 展开素材区

素材区默认是折叠的，这样不会挡住聊天内容。  
点击页面顶部的 `素材` 折叠条，展开后就能看到素材编辑区。

### 3. 填入素材

你可以按下面三种方式之一来填：

- 直接粘贴文本
  - 例如你的提纲、结论、摘要、备注
- 粘贴链接
  - 例如论文地址、文章页面、参考资料页
- 上传文件
  - 例如参考文档、已有 PPT、截图、图表

如果你同时有主题和素材，建议都保留：

- 主题负责告诉系统“要做什么”
- 素材负责告诉系统“优先用什么内容”

### 4. 点击保存或上传

文本和链接要点击 `保存`。  
文件要先选中，再点击 `上传`。

保存后，这些素材会跟当前会话绑定，后续生成 PPT 时会自动读取。

### 5. 去生成 PPT

回到下方的 `PPT 生成` 输入框，输入一个演示主题，例如：

- `企业 RAG 方案分享`
- `LLM 自主智能体研究综述`
- `基于本研究生成 PPT`

然后发送。

系统会结合：

- 你输入的主题
- 当前会话下的素材
- 研究会话的报告

一起生成 PPT。

## 素材会怎样被使用

素材不是只“保存下来”，而是会在生成流程中参与多个阶段：

- `outline`
  - 用来帮助生成结构化大纲
- `layout`
  - 帮助判断哪些页面更适合图文并列、双栏、结尾页等布局
- `schema`
  - 把素材拆成标题、要点、引用、图片、图注等元素
- `manuscript`
  - 将素材内容写入讲稿或附录

对不同类型的 PPT，素材作用略有不同：

- 常规主题 PPT
  - 素材会直接影响页面内容和讲稿
- 研究类 PPT
  - 素材会作为补充信息，和研究报告一起参与生成

## 如果你要做研究类 PPT

推荐这样做：

1. 先在 `论文研究` 里做研究，拿到研究报告
2. 再在 `PPT 生成` 里展开素材区
3. 把你额外的参考论文、示意图、提纲一起放进去
4. 直接点 `基于本研究生成 PPT`

这样系统会把：

- 研究报告
- 你的素材
- 当前会话的信息

组合成一份 PPT 初稿。

## 生成后能做什么

PPT 生成后，你可以继续做两件事：

- `质量检查`
  - 看看内容里有没有多余的调试文本、过长句子、页数不一致等问题
- `重新生成`
  - 基于已保存的 outline / layout / schema / design / plan / manuscript 重新导出 PPT

这两个按钮都在 PPT 结果消息里。

## 一个最小示例

你可以这样操作：

1. 展开素材区
2. 粘贴一段你自己的提纲：

```text
1. 背景
2. 现状
3. 方案
4. 结果
5. 展望
```

3. 再上传一张示意图或一个参考文档
4. 在 PPT 输入框里输入主题：

```text
企业知识库建设方案
```

5. 发送后生成

系统会优先围绕你提供的素材来组织内容。

## 小提醒

- 素材最好尽量短、明确、分点
- 如果有长文档，建议先放“摘要 + 关键图/表”
- 如果你想让某个素材在 PPT 中更重要，可以把它写成更明确的标题
- 当前素材区默认折叠，就是为了不挡住聊天和生成结果
